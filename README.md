# Weather Rescue Brazil

**Resgate Meteorológico Brasil**

Weather Rescue Brazil is an open-source project to rescue and digitize historical Brazilian weather records. It combines an open dataset of digitized records with an open model trained via AI-assisted human verification. The goal is to build a comprehensive, human-verified dataset of historical Brazilian weather observations that researchers and climate scientists can freely access and build upon.

Weather Rescue Brazil is an independent project. It is not affiliated with Zooniverse or the Weather Rescue / Rainfall Rescue projects, whose naming family it gratefully follows.
