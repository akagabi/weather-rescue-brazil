## O que isto muda

Muitas destas chegam num mesmo formulário impresso — *RESUMO MENSAL DAS
OBSERVAÇÕES SIMULTANEAS*, com campos Estação / Observador / Latitude. Se o
formulário for de facto padronizado, **um único perfil lê todas elas**, e o
custo de adaptação por estação cai para perto de zero.

O *Cruzador Almirante Barroso* não é uma estação terrestre: são observações
marítimas, que vão para o ICOADS e não para os arquivos de superfície.

Doc 11 traz tabelas do Rio de 1853 e 1855 — dentro da janela que o EMERLAC já
cobre (Rio 1851–1856). Servem como **verificação cruzada do método** contra
uma série já publicada, o que vale mais do que mais um mês inédito.
